## 给硬件设计同学的使用顺序

1. 在“GPIO接线总表”按“声明分类”筛选默认可用候选。禁用/非默认状态不要直接连成同时使用的网络；先核实实际装配和驱动。
2. 按“GPIO消费明细”“已引用Pinmux”回查用途、状态和源文件位置。组内每根 SDA/SCL、UART TX/RX 等单脚分工，需要实际芯片 TRM 的 MUX 表确认，不能依 DTS 数组顺序猜测。
3. 在总表填写实际芯片封装球位、VCCIO、原理图网络名、连接器脚号及签核状态。GPIO3_B3 是逻辑 PAD 名，不是 BGA 球位，传统线性号也不是运行时 GPIO 号保证。
4. 在“功能键与摇杆”补齐实体键到 GPIO 的映射。19 路 key-gpios 都是低有效声明，但没有 A/B/X/Y、方向、Start/Select/FN 的逐键名称；需真实驱动映射或样机通断测量。
5. 在“ADC模拟输入”核对音量键、播放暂停和四轴模拟摇杆的通道。ADC1/ADC2 各有多功能共享声明，必须结合电路与厂商驱动确认，而不是把每个功能另接到一根 GPIO。
6. 在“稳压器电源”“IO域供电”核对电源、使能极性和时序。电压范围是 DTS 配置，不替代负载预算、芯片规格和 IO bank 到电压域的映射。
7. 审查“复用与待核实”，处理 GPIO0_B3、GPIO0_B4 的多设备声明、卡检测相关默认复用等条目，再冻结连接表。

## 电气解释

- GPIO flags=0/1 表示标准高/低有效，不决定方向。方向若只是按“reset”“LED”等用途推断，表中会明确注明。
- `interrupts` 的 8 表示低电平 IRQ，不按普通 GPIO flags 解释。厂商 `irq-gpio` 等属性的标志仍需看厂商驱动。
- 固定稳压器 `gpio` 还要读 `enable-active-high`；缺省低有效，不能仅看 GPIO flags。当前具体配置在对应行中列明。
- 内部上拉/下拉不等于板上已装对应电阻，也不能代表上电前电平。`drive-strength` 不等于允许直接驱动外部负载的额定电流。
- DDR、DSI/USB 差分线、SARADC 模拟脚、晶振、电源和启动绑带不能由 GPIO 表完整还原。独立核心板需另行完成这些专用信号的设计。

这些限制来自输入资料的范围，不能靠扩大 DTS 表格消除。封装球位、具体 IO 电压、19 个实体键名和精确外围网络仍应由硬件+BSP共同确认。
