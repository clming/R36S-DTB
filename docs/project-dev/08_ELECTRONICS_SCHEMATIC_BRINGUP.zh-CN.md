| 路线 | 现在应做的工作 | 不必重复做的工作 | 放行门槛 |

## 6. 电源预算和器件选型的计算工作

电源轨逐路填写：额定/允许电压、负载、空闲/典型/峰值电流、启动冲击、效率、温升、允许纹波、上电顺序、测点和资料出处。CPU 动态电压和工作点按确定的器件/BSP 验证，不能根据开机成功提高频率或降低电压。

续航估算先用能量口径：`可用电池能量 Wh ÷ 实测平均电池侧功耗 W ≈ 小时`。如使用系统侧功耗，还要计入电源效率及截止前不可用容量；mAh 不能直接除以不同电压侧的电流。估算只用于选型，最终按整机试验确认。

电感按饱和电流、纹波和温升选，电容按耐压、偏压有效容量、纹波及 ESR 选；TVS/ESD 还要核对信号寄生参数。充电电压/电流/NTC 和截止条件来自电芯与 PMIC 规格。任何电池替代都要重新评审，不能只比较外形和标称 mAh。

| BOM 字段 | 必填规则 |
| --- | --- |
| 位号/数量/完整 MPN | 每个可采购器件唯一对应；不接受仅写 RK817/1GB DDR/40pin屏 |
| 厂牌/封装/电气等级 | 与原理图和 PCB 库一致，含温度、耐压和容差 |
| 采购来源/批次/交期 | 保留追溯凭证；供应商声明与实际来料分别核验 |
| 固件依赖 | DDR 初始化、panel 配置、PMIC、摇杆等标注影响 |
| 替代料 AVL | 等效判断依据、需重测项和批准人，未经批准不混装 |
| 状态 | 候选/样件确认/验证通过/量产放行分别标明 |

## 7. PCB 与投板评审

先与结构交换带版本的外形、孔位、器件最大高度、连接器和工装禁布区，再定叠层和布局。DDR、DSI、USB、SD 的阻抗/长度/间距来自原厂与叠层规则；这里不给无法追溯的统一数值。

评审顺序：封装引脚与方向 → 电源回路/去耦 → DDR 拓扑与回流 → 显示/USB/SD → ADC/音频隔离 → ESD 路径 → 工装可达 → 三维干涉 → ERC/DRC 和人工审查。板厂 DFM 只证明可制造性的一部分，不能代替电路正确性审查。

投板包包括：Gerber/钻孔或双方约定格式、叠层/阻抗要求、坐标、BOM、装配图、极性/Pin1、钢网要求、测试点图和版本清单。报价必须确认 BGA 装配与检查能力、客户供料、损耗、返修和首件放行流程。

## 8. 首次点亮：按证据逐步放行

由具备硬件调试能力的人员执行；输入电源、限流值和电池连接方式按设计确定，不提供未知主板的通用送电数值。先检查再送电，异常先断开定位。

| 顺序/任务 | 操作与观察 | 通过证据 | 失败优先排查 |
| --- | --- | --- | --- |
| B0 外观/断电 | 器件方向、焊接、关键电源对地与极性 | 显微照片、阻抗记录、设计对照 | 短路、错件、桥连、封装方向 |
| B1 电源 | 按参考上电策略检查各轨、纹波、时序和电流 | 示波器波形、测点、电源条件 | PMIC 默认配置、电感/电容、负载、使能 |
| B2 时钟/复位 | 检查规定时钟和复位释放 | 波形与信号名、探测条件 | 晶振、焊接、复位、启动脚 |
| B3 早期启动 | 电平匹配 UART，读取实际阶段日志 | BootROM/loader/U-Boot 可观测阶段记录 | loader、启动介质、串口配置 |
| B4 DDR | 正确初始化后运行内存压力与循环启动 | 型号/初始化版本、容量和错误日志 | 时序/拓扑/供电/焊接，不能只换 Linux DTB |
| B5 存储/Linux | 验证分区、内核、DTB、initrd 和 rootfs 一致性 | 启动日志、挂载与版本信息 | 实际加载文件、root=、驱动/模块 |
| B6 显示输入 | 分模块开屏/背光、逐键、四轴 | 图案、时序、输入日志 | 电源/复位/命令/线路/映射 |
| B7 声音电源外设 | 耳机/喇叭、充电/电量、双卡、各 USB 模式 | 每项独立记录并可重现 | 路由、供电角色、驱动与器件配置 |

## 9. Panel4 转新板时的软件接口问题

换屏至少审查 panel 节点、DSI lane/format/flags、供电、reset、初始化/退出命令、时序、端点与背光。修改 GPIO 同时更新 pinmux、驱动依赖和用户态映射。完整依赖与构建方式见[固件方案](09_FIRMWARE_EMULATORS_RELEASE.zh-CN.md)。

当前 Panel4 的 `native-mode = <0xa0>` 与三个时序节点 phandle 不对应；应作为待定位配置问题，不据此猜测实机驱动最终选择。其 `60Hz` 时序以 29 MHz、Htotal=732、Vtotal=661 计算约 59.94 Hz；另两节点同参数约 77.38 Hz，名字不是测量值。新板应从屏规格重建合法引用与模式；本轮未修改这些参数或运行 dtc。

## 11. 替代主平台及国内外硬件设计增量

| 工作包 | 电气/PCB 需要多做什么 | 验证与交付 |
| --- | --- | --- |
