## 3. 路线和关键路径

首版优先 A：取得书面供货和软件交付依据的替代平台成熟主板/ODM + 固定屏 + 定制结构 + 受控固件。H700 与 RK3566/RK3568 按 11 文档并行缩圈，不将零售在售作为可供板承诺。若取得不到可接受的资料、交付与供货条件，再评估 B：选定新平台参考设计基础上自研/委托主板，重新核算周期与成本。

- A 关键路径：供方确认和到样 → 固定接口与可运行系统 → 装壳手板 → 软件/电源/热与体验验证 → 开模和模具样件 → 小批试产。
- B 关键路径：芯片/DDR/PMIC 资料与 BSP → 原理图评审 → PCB/贴片 → 最小系统/DDR 点亮 → 外设与结构联调 → 改板及验证 → 模具和试产。

可以并行做需求、内容许可、原卡研究、询价和结构测量；没有固定屏/PCB 包络前不开正式模具，没有 DDR/电源依据前不投新板。两条路径不能共享一个无条件的最短交付承诺。

## 4. 阶段门：完成什么才进入下一步

| 阶段 | 建议资源/数量 | 必须交付 | 放行条件 |
| --- | --- | --- | --- |
| G0 立项与来源 | 约 1–2 周，等待资料/物流另计 | 产品决策表、样机档案、供方资料评分、成本模型、路线决定 | 关键料来源与维护路径可信；重大缺口有明确解决方式 |
| G1 可操作演示 | A 在资料/可用板到位后约 1–2 周 | 一个合法演示、完整操作链、备用卡恢复、初步功耗 | 显示/输入/声音/存档/关机闭环可重复 |
| EVT 工程验证 | 候选 5–10 台；A 总体约 4–8 周区间 | 固定首版接口、工程壳、软件基线、故障闭环 | 全 P0 已有结果，无 S0/S1 阻塞；暂缓项有决定 |
| DVT 设计验证 | 候选 10–20 台，按覆盖需求调整 | 冻结 BOM/PCB/结构/固件、热/充电/可靠性、恢复报告 | 最终材料/模具件验证完成，规格和缺陷边界确定 |
| PVT 生产验证 | 候选 30–100 台，不代表统计保证 | 生产工艺、产测工装、工时/良率、追溯与返修 | 工艺和测试可重复；重大问题零未闭环 |
| MP 量产 | 数量和日期以订单评审为准 | 受控发布包、AVL、产线/售后与备料计划 | 设计、供应、质量及销售要求全部评审通过 |

以上样本和周期为项目预算起点，不是认证抽样方案；A 首轮小批冻结可按 8–16 周或更长评估，B 按 16–28 周或更长评估，资料审批、供货、改板/修模及构建难点都可能延长。PVT 不能只因为“做出了几十台”就通过。

| IQC 来料 | 核对板/屏/电池/卡/壳型号与批次，抽检关键项 | AVL、照片、检验结果和批次隔离 |
| PCB 首件/板测 | 工艺检查、电源/启动/输入/声音/USB/充电 | 电气上下限来自已签定测试规范 |
| 写卡 | 选定受控镜像、物理卡核对、写入并校验 | 镜像版本/哈希、卡型号/批次、工具、结果 |
| 预装与整机装配 | 按 SOP 固定屏/电池/线束/肩键，记录紧固 | 关键位置照片、操作工、工时和返拆原因 |
| 整机 FCT | 冷启动、测试图/背光、全部键轴、扬声器/耳机、充电/电量、卡/USB | 配置 ID、序列号、每项原始结果；强制关机不是正常流程 |
| 老化/可靠性抽检 | 根据质量计划做负载/热/充电/结构试验 | 指定条件、时长、温度/电流/异常和回归结果 |
| OQC/包装 | 外观、配置版本、合法演示、附件和恢复入口 | 抽检记录、版本标签、装箱清单 |
| 返修 | 隔离、分析、更换/修复、重测 | 原故障、根因、修复动作、版本变化和最终结果 |

序列号至少关联：PCB/BOM、屏、DDR/PMIC 若有差异、电池批次、卡批次、镜像/DT 配置、装配日期、产测版本和结果。不要仅靠开机 logo 或同名 DTB 追溯固件。

`一次通过率 FPY = 未经返修即通过的台数 / 首次测试台数`；返修后总通过率单独记录。例如 50 台中 45 台首次通过、5 台返修后通过，则 FPY=90%，最终通过率=100%。不得把后者宣传为一次良率；少量样本也不能证明长期可靠性。

## 11. 变更、发布与售后闭环

任何换屏/DDR/电池/PMIC/卡/PCB 或核心版本，先填变更单：原/新料与版本、原因、库存、结构/电气/BSP/性能/许可影响、验证范围、批准人、生效批次与回退。采购不得以“可兼容”绕过测试，软件不得只按文件名覆盖全部卡。

发布包由硬件、结构、软件、测试四方核对，包含制造文件、BOM/AVL、装配/产测、镜像与哈希、源码/许可、恢复说明、验收和已知问题。普通用户入口只呈现可操作说明，调试地址和工程内部步骤放售后/工程资料。

售后工单最少记录：序列号、硬件配置、固件版本、卡/电源、现象、复现步骤、日志/照片、处理和结果。先用对应恢复方案定位软件与卡问题，再按安全流程检查硬件；电池/充电异常不能简单建议反复换镜像。

## 12. 项目经理每周只需要核对的六项结果

1. 本周新增了哪些可审查证据，分别是“资料取得、设计完成、编译通过、实机通过、制造通过”中的哪一层。
2. S0/S1、关键资料、长交期物料和接口变更是否闭环，谁在什么日期交付。
3. 最新样机配置与镜像是否一一对应，第二人是否能恢复，软件是否仍依赖未知来源文件。
4. 实际支出/新报价/改板修模与计划差异，是否影响首版范围或关键路径。
5. 供方变更、内容许可、目标市场验证与售后准备是否有明确负责人和证据。
6. 下一阶段门的缺件清单；未达标就调整范围或日期，不以演示视频替代阶段放行。

## 13. 国内与海外销售的新增工作包（2026-10-29）

### 13.1 国家、配置、责任主体先于送检冻结

首发不是“国内版/海外版”两个笼统名称。G0 建立 `目标国家/地区—产品/SKU—无线模块/天线—电池/电源—固件—内容—语言—进口与责任主体—渠道—测试/注册—售后` 矩阵。建议先中国大陆加美国或明确的欧盟首批国家，最终由商业调查决定；未评审地区不开放发货。

| --- | --- | --- |

| 贸易角色 | 制造主体及合同交付明确 | 谁是出口商、进口商、卖家、欧盟责任经济运营者、美国 SDoC 责任方；不能让工厂口头包办 |
| 包装 | 产品 ID、输入额定、电池信息、序列/批次可追溯 | 目的地语言、所需标识/地址、充电信息、回收、警告、条码和附件分别签样 |
| 售后 | 原生/即时存档区分、用户备份、诊断和配件 | 本地退货地址、运费/税、维修/更换、服务语言、备件和数据处理规则 |

### 13.5 认证、运输、服务要怎样计入预算

新增 NRE：适用性评估、EMC/射频预扫与整改、正式测试及复测、技术文件/DoC、包装/语言、安全测试、漏洞/更新机制、地区注册与代理。持续成本：报告维护、回收/申报、海外仓/履约、客服、备件、更新支持和退换修。

测试样本包含最坏硬件/无线/电源/负载配置，不能随便拿另一款旧机报告贴牌。芯片、模组、电池或适配器证书要核对型号、版本、范围和实际产品，ODM 合同明确变更和复测责任。

[IATA 2026 电池运输指南](https://www.iata.org/contentassets/05e6d8742b0047259bf3a700bc9d42b9/lithium-battery-guidance-document.pdf)可用于组织运输分类和资料；实际承运按适用规则及承运商条件确认，指南本身不替代完整运输规则。UN38.3 测试摘要不是 CE/FCC 证书，普通 SDS 也不能替代全部电池运输证据；装机、同箱与单独电池的 SOC/包装和返修限制不能混用。

欧盟通常适用至少两年法定商品保证，远程销售一般有 14 日撤回期并存在例外/国家细节；商业保修不能削减法定权利。按[欧盟官方消费者权利指引](https://europa.eu/youreurope/citizens/consumers/shopping/shopping-consumer-rights/)由销售方明确义务，P&L 纳入退货/换机和本地履约，而不是仅沿用国内供应商短期返修条款。

### 13.6 海外进入阶段门的增量条件
