# RK3326 掌机：结构测绘、机构设计与开模执行方案

版本：V0.1；日期：2026-10-29。承接[工程工作分解](02_ENGINEERING_WORK_BREAKDOWN.zh-CN.md)。本文件用于给结构工程师、手板厂和模厂下发任务；当前没有完成 CAD、尺寸实测或模具设计，表内待测值必须由实物和供应商图纸填写。

2026-10-29 更新：RK3326 原机只作测绘参考；新平台按[11 替换方案](11_RK3326_REPLACEMENT_STRATEGY.zh-CN.md)冻结，先更新 PCB/屏/电池包络再开模。海外特别是欧盟 2027 年相关电池拆换要求进入本文第 10 节与[10 手册第 13 节](10_PROJECT_PROCUREMENT_PILOT_EXECUTION.zh-CN.md#13-国内与海外销售的新增工作包2026-10-29)；不沿用旧主板轮廓直接冻结新壳。

## 1. 结构开发输入与坐标定义

主板照片：[正面 p1-11](p1-11.jpg)、[反面 p1-12](p1-12.jpg)，用户已确认属于同一主板。正面丝印 `R36S-V12 2023-08-18`、反面丝印 `V2.1_20250331` 分别记录；不按丝印差异拆成两套机械设计。

首轮建议准备 3 台同配置样机：一台保留为完整体验对照，一台测绘拆装，一台用于结构与电气联调。数量为资源建议，尚未采购。所有部件拆前编号，拍摄排线、接触面、线序、泡棉和螺钉位置；不能仅凭照片比例建立可开模尺寸。

建议总装定义：Z=0 为主 PCB 选定安装基准面，X/Y 原点为定位孔中心，第二定位特征约束旋转；具体基准由结构和 PCB 工程师共同冻结。坐标方向在二维图和 STEP 中画明，避免从正反面看图导致镜像错误。

| 输入项 | 收集方式 | 交付内容 | 缺失时阻塞什么 |
| --- | --- | --- | --- |
| PCB 外形及定位 | 卡尺、影像/扫描与 ECAD 外形交叉复核 | 外形 DXF/STEP、孔径、坐标、公差、板厚 | 机壳、螺柱和接口窗口冻结 |
| 屏模组与 FPC | 完整料号、机械图、供应商图纸 | 外框/视区/厚度、排线位置及最小弯折要求 | 前框、镜片、排线通道 |
| 摇杆与开关 | 成品模组图纸和装配样件 | 中心、高度、最大偏转包络、固定点 | 操作面高度和键帽空间 |
| 电池包 | 精确型号与允许尺寸范围 | 尺寸、引线、保护板、连接器、允许固定方式 | 电池仓、后盖和安全间隙 |
| 连接器 | 厂商封装/三维图 | 插头包络、插拔方向、PCB 固定要求 | USB/耳机/TF 窗口 |
| 扬声器与辅料 | 模组、泡棉、胶与线束样品 | 安装包络、声腔、线槽、压缩范围 | 音质、装配和防夹线 |

| ME-01 前壳 | 显示窗、键导向、摇杆窗口、屏定位和防尘 | 原生 CAD、STEP、关键尺寸图 | 可视区无遮挡；正常握持不顶屏 |

| ME-04 导电胶/开关 | 胶碗与键帽/PCB 接触高度配合 | 供应商图、压缩/力程记录 | 压力和回弹一致，装壳后不预触发 |
| ME-05 四肩键 | 支点/转轴、开关落点、止挡和抗脱落 | 四键装配图与防呆定义 | 中部/边缘按压均触发，释放后复位 |

| ME-07 摇杆固定 | 安装平面、帽体包络、排线走向 | 装配图和运动包络 | 四轴最大偏转不碰壳、不拉扯排线 |
| ME-08 声学/导光 | 喇叭密封、网孔、隔振、导光和遮光 | 泡棉/胶/导光件图 | 无可复现壳振；暗室无明显串光 |

壳体材料、壁厚、筋厚、螺柱尺寸、拔模角和扭矩不在无资料时定死。结构工程师先提出方案，模厂根据选定树脂与模具工艺给出 DFM，双方签定后进入二维图。

## 4. 必须计算的尺寸链

### 4.1 显示与背部堆叠

为每层列厚度上下限：镜片、胶、压框、屏、支架、PCB 及器件、电池、后盖。分别检查屏的承压位置、最差间隙和螺钉锁紧变形。外壳闭合不得通过压软包电池或压屏玻璃来补偿堆叠误差。

### 4.2 按键自由间隙与有效行程

将键帽高度、壳体导向、胶碗/开关高度、PCB 安装面和锁紧变形纳入尺寸链。定义“未按时不触发”和“到止挡前可靠触发”两条约束，分别按最大/最小公差组合计算；不能只在名义 CAD 中看不干涉。

### 4.3 接口和线束

USB 窗口考虑插头护套和正反插，不只露出金属口；TF 考虑推入/弹出和取卡手指空间。线束/排线按供应商弯折与应变要求设计，连接器锁扣应能由工具或手指到达，后盖不能把线硬折在焊点或 FPC 出口。

| 接口控制字段 | 填写要求 |
| --- | --- |
| 机械基准/版本 | 与 PCB 和总装共用基准；变更必须告知对方 |
| 最大包络/禁布 | 包含焊点、插头、卡、摇杆运动、工装与维修路径 |
| 关键尺寸与公差 | 标出检验方法和责任；不能整张图只写一个通用公差 |
| 屏/电池/线束 ID | 绑定完整料号；供应商替代件先做差异评审 |
| 状态 | 待测/已测/手板验证/模具样件验证，分别标识 |

## 5. 三轮样件与开模门槛

| 阶段 | 样件与目标 | 必做检查 | 未通过怎么处理 |
| --- | --- | --- | --- |
| M0 测绘堆叠 | 低成本打印壳/局部剖切模型 | 孔位、接口、屏窗、摇杆包络、装配顺序 | 调 CAD；暂不评颜色和注塑寿命 |
| M1 功能手板 | 接近目标刚度/表面的完整样机，工艺由供应商确认 | 输入、握持、肩键、声学、漏光、温升和拆修 | 缺陷逐项关闭后再作开模评审 |
| T0/T1 模具样件 | 目标材料与工艺 | 缩水、翘曲、尺寸链、外观、紧固与可靠性复测 | 模具修正并回归；不以手板通过代替 |

开模前必须具备：冻结的 PCB/屏/电池接口、可用软件基线、M1 全功能记录、无顶屏/压电池/持续压键问题、模具 DFM、材料与颜色样、尺寸检验计划、模具归属和修改费用边界。提前开模只会把接口不确定性转化为改模成本。

## 6. 结构验证与装配验收

以下为内部工程建议，测试高度、次数、温度范围和判据由产品及测试负责人在 DVT 计划冻结，不代表法定认证条件。

| 项目 | 方法 | 必留证据 |
| --- | --- | --- |
| 装配重复性 | 至少 3 台完整装配，记录工时、返拆和异物 | 装配问题表、首件照片、版本 |
| 拆修 | 同一台按 SOP 拆装 5 轮候选 | 螺柱/卡扣/排线损伤、扭矩与功能回归 |
| 手感与触达 | 5 名不同手型人员各试用 30 分钟候选 | 误触/疲劳位置、问题动作及改进决定 |
| 肩键与动作键 | 寿命治具前先跑小批循环，冻结力/行程和次数 | 试前/试后手感、电气触发和外观 |
| 跌落/扭转 | 定义落点、方向、状态、表面和次数后执行 | 外观、内件固定、屏、输入、充电全回归 |
| 热与充电 | 最终壳体内运行实际高负载及边充边玩 | 外壳/电池/芯片测点、环境和时间曲线 |
| 声学与漏光 | 固定音源/音量、暗室独立开关背光和状态灯 | 扫频录像、照片和结构差异 |
| 包装运输 | 使用最终包装并约定试验方案 | 屏与摇杆保护、端口、电池固定及整机回归 |

## 7. 可交给工厂的结构包

交付目录由团队另行建立，当前没有这些设计产物：`原生CAD/STEP/二维尺寸图/机械BOM/材料与外观样板/胶泡棉与线束图/装配SOP/拆修SOP/DFM/检验报告/变更记录`。每份标版本和日期，所有外发包附文件清单与哈希。

BOM 必填：零件 ID、完整料号、图纸版本、材料/表面、颜色样号、数量、装配位置、供应商、替代范围和检验方法。螺钉、胶、泡棉、导光、绝缘和腕带等辅件必须逐件列出，不能只写“辅料一包”。

模厂报价需拆分：模具数量/穴数、材料、寿命约定、试模与修模范围、样件数、交期起算条件、模具存放与归属、维修、单件价和最小订单量。外观标准用签样件/缺陷图界定，不能只写“无明显瑕疵”。

## 8. 官方制造联系入口与询价资料

[嘉立创官方业务联系页](https://www.jlc.com/portal/1/vcontact.html)列出 3D、CNC、手板复模及 PCB/SMT 等业务入口，可用于索取样件工艺评估和制造报价。其公开服务热线为 `150-7448-1235`，页面标明周一至周六 09:00～18:00。联系前重新核对页面；这不是已确定的模具或整机 ODM 合作方，也不表示已验证其能承接本项目所有工艺。

外发资料顺序：第一轮给脱敏包络和材料/数量/精度需求，确认能力与保密安排；第二轮给受控 STEP、二维图和关键尺寸；第三轮依据 DFM 修订再签定报价。重点询问透明料试样、螺柱/卡扣工艺、缩水翘曲、屏窗公差、手板与量产材料差异。未核实原机屏和电池制造商，不能编造其官网联系方式。

## 9. 第一轮十个工作日任务

| 时间 | 责任人 | 当天应能审查的输出 |
| --- | --- | --- |
| D1–D2 | 结构+硬件 | 样机编号、拆装图册、DIM 表、完整料号缺口 |
| D3–D4 | 结构 | 总装堆叠 V0.1、外形/接口坐标、尺寸链初版 |
| D5 | 结构+PCB+BSP | 接口评审；冻结首轮孔位/屏/摇杆包络 |
| D6–D7 | 结构+手板厂 | M0 图纸和 DFM、确认的报价与交期；等待加工另计 |
| D8–D10 | 结构+测试 | 若 M0 到样则装配验证；未到样则完成键帽、肩键及装配 SOP 评审 |

本轮退出条件是“测绘与首轮设计输入可审查”，不是承诺十天获得量产壳。图纸、样件和真实验证记录完成后才能分别标为设计完成、装配通过或量产验证通过。

国内、美国和欧盟可优先共用壳体，以地区标签/包材和必要的硬件差异管理。新增散热孔、主动风扇、金属壳或双屏/铰链时重新评估整机可靠性、EMC/天线与维护，原手板验证不能直接继承。
